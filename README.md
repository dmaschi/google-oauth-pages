# Google OAuth information pages

Static public pages for the personal Google OAuth project `sincere-cortex-484000-a5`, whose consent-screen application name is `mcpGmail`.

Based on the simple card layout of https://github.com/dmaschi/ebay-oauth-pages; the eBay repository is not modified.

Only `index.html` and `privacy-policy.html` belong on the public site. Never upload credentials, Google account data, local logs, or the application source here.

Intended repository: https://github.com/dmaschi/google-oauth-pages

Intended homepage: https://dmaschi.github.io/google-oauth-pages/

Intended privacy policy: https://dmaschi.github.io/google-oauth-pages/privacy-policy.html

Publishing these pages does not itself change Google Cloud settings or restore an expired OAuth token. Review the pages for accuracy before using the URLs in Google Cloud; Google may also require ownership verification.
