mcpGmail

Personal Google Workspace integration and Google Tasks Desktop

This application is operated by Dario Maschi to work with his own Google account. It is not a public account-management service.

What the application does

The Google Workspace MCP integration lets the account owner use authorized software assistants to search, read, and manage Gmail, Drive files, calendars, documents, spreadsheets, presentations, forms, tasks, contacts, Google Chat, and Apps Script projects. Available operations depend on the permissions granted and the owner's requests.

The Google Tasks Desktop component displays and manages the owner's task lists in a KDE desktop popup. It can create tasks, mark completion, and move tasks between the Day Tasks and All Tasks lists.

Why Google access is requested

Google permissions allow these tools to retrieve account information and perform requested operations through Google's APIs. Access is authorized using Google's OAuth consent flow; the tools do not need the owner's Google password.

This website contains only application information. It does not display Google account data or collect Google credentials.
